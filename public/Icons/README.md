# Icônes des Compétences

Ce dossier contient les icônes pour chaque catégorie et compétence affichée dans la section Skills du portfolio.

## Format requis

- Format : PNG
- Taille recommandée : 
  - Catégories : 48x48 pixels
  - Compétences : 32x32 pixels
- Fond transparent recommandé
- Nommage : en minuscules avec des tirets (exemple : `frontend.png`, `react.png`)

## Note

Si une icône est manquante, le composant `ImageWithFallback` affichera automatiquement l'image de secours (`cam.jpg`). Cependant, pour une présentation professionnelle, il est recommandé d'ajouter toutes les icônes nécessaires.

## Optimisation des icônes

Pour optimiser les icônes avant de les ajouter :
1. Redimensionnez-les à la bonne taille (48x48 pour les catégories, 32x32 pour les compétences)
2. Utilisez des outils comme [TinyPNG](https://tinypng.com/) pour la compression
3. Assurez-vous qu'elles ont un fond transparent
4. Gardez un style cohérent entre toutes les icônes
